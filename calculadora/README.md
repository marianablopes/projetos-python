# Calculadora Python (POO)

Calculadora de terminal desenvolvida em Python, aplicando Programação
Orientada a Objetos, operações aritméticas, operações lógicas e
tratamento de erros.

Projeto de estudo, com apoio de IA para revisão de código e boas práticas.

## Funcionalidades

- Operações aritméticas: soma, subtração, multiplicação e divisão
- Operações lógicas: AND, OR e NOT
- Histórico de operações realizadas na sessão
- Validação de entrada (números e operadores)
- Tratamento de divisão por zero

## Como executar

```bash
python calculadora.py
```

## Exemplo de uso
Digite o operador (+, -, *, /, &, |, !, H, S): +
Digite o 1º número: 4
Digite o 2º número: 6

Resultado: 4.0 + 6.0 = 10.0
